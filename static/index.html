DEVELOPER API

Apne app me bhi laga lo.

Same server POST /detect expose karta hai. Base64 JPEG bhejo, detections lo. Interactive docs →

  • GET /health detector status
  • GET /labels default label list
  • POST /detect run detection
curl -X POST http://localhost:8000/detect \
  -H "Content-Type: application/json" \
  -d '{
    "image": "data:image/jpeg;base64,/9j/4AAQ...",
    "labels": ["pen", "dog", "cup"],
    "threshold": 0.15
  }'
